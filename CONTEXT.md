# Elite Dangerous galaxy map

A browser interface for exploring the Elite Dangerous galaxy generated by PEGE and presented by ED3DM.

## Products

**ED3D**:
The 2015–2017 gbiobob browser plugin (`Ed3d.init`) that embeds a JSON-driven star map.
_Avoid_: ED3DM, PEGE

**ED3DM**:
The embeddable map presentation library. It owns interaction, camera behavior, selection, themes, grids, and rendering.
_Avoid_: PEGE, ED3D, Map app

**ED3DM-WebGPU**:
This repository: the ED3DM library and its first-party Map app.
_Avoid_: using this string as the constructor; PEGE

**PEGE**:
The Procedural Elite Galaxy Engine that owns System existence, identity, position, and generated naming.
_Avoid_: renderer, Map app, catalogue, external mapping API

**Map app**:
The interactive website that combines ED3DM presentation with a PEGE galaxy source.
_Avoid_: ED3DM, PEGE, Host

**Host**:
A page that embeds ED3DM and supplies a galaxy source plus presentation options.
_Avoid_: Map app; PEGE

## Galaxy

**System**:
A star system identified by an ID64 and positioned in Elite space.
_Avoid_: planet, body, station, particle, orb

**Authored System**:
A generated System whose final display name is supplied by PEGE's authored catalogue. Any catalogue position knowledge needed to reconstruct its generated slot remains internal to PEGE.
_Avoid_: procedural System, hand-placed orb

**Procedural System**:
A System whose existence and position are generated deterministically by PEGE’s ordinary or constrained branch.
_Avoid_: impostor, placeholder, estimated point

**System identity**:
The ID64 retained with a System across generation, rendering, selection, naming, and enrichment.
_Avoid_: display name as identity; array index as durable identity

**Stellar profile**:
Physical and compositional information about a System’s stars, including class, radius, mass, temperature, and display color. Profile coverage is separate from PEGE spatial generation.
_Avoid_: System position; inventing profile values from a name or ID64

**Elite space**:
Sol-relative XYZ coordinates measured in light-years, with Sol at `(0,0,0)`.
_Avoid_: renderer axes; boxel-grid coordinates

**Boxel**:
Elite’s nested cubic grid of space, from mass code **a** (10 ly) through **h** (1280 ly).
_Avoid_: camera LOD level; flat X/Z cell

**Mass code**:
The immutable **a–h** size class encoded in one System’s ID64.
_Avoid_: Grid level; changing a System’s mass code with zoom

## Presentation

**Orb**:
The camera-facing sprite that visually represents one System.
_Avoid_: System, planet, 3D sphere, impostor

**LOD**:
The Map app policy that combines a persistent whole-galaxy overview, view-local Spatial detail tiles, and Exact local detail. Lower detail states are stable prefixes of the same PEGE selections.
_Avoid_: random reshuffling; placeholder density points

**Persistent overview**:
A deterministic, coverage-first 50,000-System PEGE view across all eight mass codes and the galaxy's full X/Y/Z bounds. It remains the far-field floor at every LOD, and authored names are part of this one population.
_Avoid_: dust, impostor field, camera bubble

**Spatial detail tile**:
A stable PEGE world-space volume that contributes a population-guided sample of real Systems intersecting the current view. Its identity is independent of camera motion and neighboring tile requests.
_Avoid_: camera bubble, catalogue tile, renderer chunk

**Radial mass-code residency**:
A planar local-detail stack anchored to the last selected System, or otherwise to the camera's X/Z focus at the current height. The focused 1,280-ly h boxel receives the full local share; successively thinner g-, f-, and e-width bands surround it on all four X/Z sides with decreasing shares. PEGE's stable storage keys remain h-sized, and ED3DM clips genuine results into each complete geometric band before publishing it.
_Avoid_: frustum-directed wedges; partially published bands; moving generated Systems

**Exact local detail**:
Complete real-System enumeration inside a deliberately small area used at the closest map scale.
_Avoid_: representative sample, whole galaxy

**All Resident**:
The warned maximum LOD state that applies no extra ED3DM thinning to the overview and camera-resident detail supplied by PEGE.
_Avoid_: implying that every System in the galaxy can be resident in browser memory at once; a silent point cap

**Far-field presentation mask**:
Independently salted, stable ID64-keyed variation in point opacity and size used only at whole-galaxy distance to prevent genuine coordinate phases from accumulating into uniform bright rows. It fades out toward local views, retains a nonzero floor, and never changes System identity, position, naming, or cache residency.
_Avoid_: coordinate jitter; synthetic stars; random reshuffling

**Aggregate density glow**:
A non-pickable second sprite layer anchored to Persistent overview System coordinates. Its brightness communicates the much larger represented population at galaxy scale and fades to zero before exact-local range. It creates no System identity, coordinate, name, search result, or selection target.
_Avoid_: fake star; synthetic System; selectable impostor

**Selection rail**:
A connection from the selected System to one of its nearest resident detail neighbors. While a selection is held, only current rail endpoints are eligible as the next selection; empty-space deselection restores unrestricted factual-System picking.
_Avoid_: route data; selecting the aggregate density glow

**Grid level**:
The user-selected boxel-lattice resolution currently illustrated by the Map app. It remains fixed while zoom changes; the camera may independently choose a coarser residency boxel without changing this filter or any System’s mass code.
_Avoid_: System mass code

**Grid view**:
Either the flat X/Z lattice or the 3D wireframe of boxels at the current Grid level.
_Avoid_: drawing every nested child lattice simultaneously

**Y neighbors**:
The symmetric count of adjacent boxel layers shown above and below the current layer in the 3D Grid view.
_Avoid_: total layer count, double stack

**Artistic theme**:
Paper or charcoal presentation using ED3DM-owned colors and styling.
_Avoid_: realistic stellar color

**Realistic theme**:
Presentation that uses a Stellar profile’s primary-star display color and radius when those values are available, otherwise neutral documented fallbacks.
_Avoid_: name-hashed spectral color; invented physical data

**Selection enrichment**:
Optional details requested only after a System is selected; it does not determine galaxy membership or position.
_Avoid_: galaxy source, mandatory runtime dependency

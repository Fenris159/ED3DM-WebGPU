# PEGE owns galaxy generation

ED3DM-WebGPU uses PEGE as the first-party Map app’s source of System existence, identity, position, generated naming, and primary Stellar profiles instead of shipping placeholder JSON overview and tile catalogues. PEGE runs behind a galaxy-source seam and ED3DM retains ownership of interaction, camera state, themes, LOD policy, grids, and rendering. This avoids hosting a row-per-System galaxy catalogue while keeping presentation independent of the engine’s Worker and packed-record implementation.
